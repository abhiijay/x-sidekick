# Anchor bank

**The ONLY source for lived-experience / stake claims in any founder-voice
content** (X posts, X replies, and future Reddit/LinkedIn writers). A claim not
in this file and not said by Bro in the current session = unavailable. Inventing
one - even with a confidence estimate attached - is fabrication and has already
gotten drafts rejected.

Difference from `ssb-content-research-bank.md`: that file holds EXTERNAL
verifiable facts with citations (for blogs). This file holds BRO'S OWN receipts:
things that happened to him, verified. Both are append-only banks.

## How this file updates (protocol)

1. **Trigger phrase:** Bro says "add to anchor bank" (or close variants) ->
   append a dated entry under the right tag, with the source of verification.
2. **Weekly harvest:** the weekly review (guides/weekly-report-runbook.md) checks
   the week's shipped work + KPIs for new receipts and appends them.
3. Entries that stop being true get moved to the never-claim list or corrected,
   never silently deleted. Stale receipts hurt more than missing ones.
