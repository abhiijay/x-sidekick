### Saving tabs in Safari (verified 2026-06-14 for how-to-save-tabs-safari)

- **Claim:** Safari's "Add Bookmarks for These [N] Tabs" (Bookmarks menu) saves every open tab in the current window into one named bookmark folder; control-click the folder and choose Open in New Tabs to restore the whole set at once. It is a permanent snapshot, not a live link (reopening creates fresh tabs, does not update with later changes)
  **Source:** iDownloadBlog walkthrough of the Safari feature - https://www.idownloadblog.com/2019/12/18/save-open-safari-tabs-bookmarks-mac/
  **Citation date:** 2026-06-14
  **Confidence:** high
- **Claim:** "Safari opens with: All windows from last session" (Safari > Settings > General) auto-restores the last session on launch; History > "Reopen All Windows from Last Session" triggers it manually; Cmd+Shift+T reopens the most recently closed tab, stepping back through recently closed items
  **Source:** SigmaOS Safari restore guide - https://sigmaos.com/tips/browsers/how-to-restore-lost-tabs-on-safari
  **Citation date:** 2026-06-14
  **Confidence:** high
- **Claim:** Safari Tab Group metadata lives in the Safari container at ~/Library/Containers/com.apple.Safari/Data/Library/Safari/; a corrupted profile or bad macOS update can disrupt Tab Groups, and Time Machine is the recovery path
  **Source:** Apple Community thread - https://discussions.apple.com/thread/256210284
  **Citation date:** 2026-06-14
  **Confidence:** medium (community thread, not an official doc; hedge the container-path recovery claim)
- **Claim:** Safari has supported Web Extensions since Safari 14, and session-saving extensions exist (e.g. SessionRestore for Safari, Tab Space), but they are typically paid Mac App Store apps and Safari's extension model has historically given session managers fewer hooks than equivalent Chrome/Firefox extensions
  **Source:** SessionRestore for Safari (Mac App Store) - https://apps.apple.com/us/app/sessionrestore-for-safari/id1463334954 ; Tab Session Manager Safari 14 porting issue (GitHub) - https://github.com/sienori/Tab-Session-Manager/issues/631
  **Citation date:** 2026-06-14
  **Confidence:** medium (extension-capability gap is from a porting discussion + product listings, not a single Apple statement; hedge as "historically fewer hooks")

### Pinned tabs in Safari (verified 2026-07-04 for how-to-pin-tabs-every-browser-mac)

- **Claim:** Safari offers three ways to pin a tab: right-click the tab and choose Pin Tab, use the Window menu and choose Pin Tab, or drag the tab to the far left of the tab bar until it snaps to a favicon. A pinned tab in Safari then appears automatically in every Safari window and persists across quit and relaunch with no startup setting required. This cross-window pin behavior is Safari-only among mainstream Mac browsers (Chromium browsers pin per-profile, Firefox pins per-window)
  **Source:** Apple Safari User Guide - Pin frequently visited websites - https://support.apple.com/guide/safari/pin-frequently-visited-websites-ibrw0495694f/mac
  **Citation date:** 2026-07-04
  **Confidence:** high

### Battery and power efficiency (verified 2026-06-27 for best-browser-for-photographers-mac-2026)

Margins narrow against Chromium browsers in some real-world tests, but Safari remains the safest bet for long battery life.

### Mac focus and distraction tools (verified 2026-07-05 for how-to-reduce-browser-distractions-mac)

- **Claim:** macOS Focus (System Settings > Focus) pauses and silences notifications or allows only chosen people/apps, and syncs across Apple devices. A Focus filter can tell Safari to show a specific Tab Group while that Focus is on; the Safari filter is Safari-only and swaps which Tab Group shows rather than hiding tabs in other browsers
  **Source:** Apple Support - Set up a Focus on Mac - https://support.apple.com/guide/mac-help/set-up-a-focus-to-stay-on-task-mchl613dc43f/mac
  **Citation date:** 2026-07-05
  **Confidence:** high
- **Claim:** macOS Screen Time can set a time limit on a website (System Settings > Screen Time > App Limits > Add Limit > Websites category), but on a Mac that website limit is enforced mainly in Safari; the same site opens normally in Chrome, Firefox, or Edge unless each is restricted separately. This is a common gap users hit
  **Source:** Apple Support - Set time limits for apps and websites in Screen Time on Mac - https://support.apple.com/guide/mac-help/set-time-limits-for-apps-and-websites-mchl630bc02f/mac ; Ask MetaFilter thread on Screen Time web limits and Chrome/Edge - https://ask.metafilter.com/372496/Does-Screen-Time-web-page-limits-work-on-a-Mac-with-Chrome-or-Edge
  **Citation date:** 2026-07-05
  **Confidence:** high
- **Claim:** Safari Distraction Control hides chosen items on a webpage: click the Smart Search field, choose Hide Distracting Items, click each element, then Done (a blue crossed-out eye icon in the address bar indicates hidden items). It is NOT an ad blocker and works best on static elements, so content that reloads or rotates can reappear
  **Source:** Apple Support - Hide distracting items on webpages in Safari - https://support.apple.com/en-us/120682 ; Intego Mac Security Blog - https://www.intego.com/mac-security-blog/how-to-use-distraction-control-in-safari-to-remove-unwanted-web-page-elements/
  **Citation date:** 2026-07-05
  **Confidence:** high
- **Claim:** Dedicated site blockers (SelfControl, Freedom, Cold Turkey) block distracting sites system-wide across every browser for a set timer, unlike Screen Time's mostly-Safari website limits. SelfControl is free and open source and cannot be undone by quitting the app or restarting the Mac while the timer runs
  **Source:** MakeUseOf - 6 Mac Apps to Reduce Distractions and Help You Focus - https://www.makeuseof.com/tag/mac-apps-reduce-distractions/
  **Citation date:** 2026-07-05
  **Confidence:** medium (blocker behavior from a roundup + tool docs, not a single primary source; SelfControl uncancelable-timer behavior is the tool's documented design)
