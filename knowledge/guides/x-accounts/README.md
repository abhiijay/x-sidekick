skill drafting for X. Each profile answers: who is this account, what voice, what
can be claimed here, what has worked, what is banned.

- Profile = account DATA only. Craft rules (moves, hooks, QC) stay in
  `guides/skill-x-post-writer-guide.md` and the shared example bank.

  own files; profiles link to them and hold only the distilled per-account layer.

  `guides/skill-x-post-writer-guide.md` Step 0. No skill repackaging needed.
